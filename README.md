# Инструмент контроля качества данных
Проверка данных из базы данных или локальных файлов по настраиваемым шаблонам.

## Что умеет
- Подключение к PostgreSQL/Neon
- Анализ пропусков, дубликатов, выбросов, корреляций
- Проверка по готовым правилам (обязательные поля, формат почты/телефона, диапазоны и т.д.)
- Вывод отчётов в читаемом виде
