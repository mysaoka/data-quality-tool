# Инструмент контроля качества данных
Универсальный инструмент для проверки качества данных из базы данных PostgreSQL/Neon и локальных файлов.

## Что умеет инструмент
- Подключение к общей базе данных по готовой конфигурации
- Автоматический анализ: пропуски, дубликаты, выбросы, корреляции, типы данных
- Проверка по настраиваемым шаблонам (обязательные поля, формат, диапазоны, уникальность и т.д.)
- Вывод отчётов в структурированном удобном виде

---

## Как начать работать
### 1. Получи доступ к репозиторию
Скопируй проект себе на компьютер:
```bash
git clone https://github.com/mysaoka/data-quality-tool.git
cd data-quality-tool
```
2. Установи необходимые библиотеки
Открой терминал в папке проекта и запусти:
```bash
Run
pip install pandas numpy scipy pydantic psycopg2-binary sqlalchemy python-dotenv
```
3. Настрой подключение к базе данных
Я отправлю тебе готовый файл конфигурации db_config.yaml:
Положи этот файл в папку config/ проекта
Никому не отправляй и не заливай на GitHub этот файл — там хранятся секретные данные доступа
Структура папок должна получиться такой:
```plaintext
data-quality-tool/
├── config/
│   └── db_config.yaml    ← сюда положи полученный файл
├── services/
├── checks/
├── main.py
└── README.md
```
4. Запусти инструмент
```bash
Run
python main.py
```
Как работать с кодом
Основные файлы проекта
Таблица
Файл / папка	Назначение
main.py	Основной файл для запуска, здесь настраивается список таблиц для проверки
services/db_connector.py	Подключение к базе данных, загрузка таблиц
services/data_analyzer.py	Все методы анализа и проверки по шаблонам
checks/templates/	Шаблоны проверок для разных таблиц (students, products и т.д.)
checks/	Описания отдельных правил проверок (обязательные поля, почта, даты и т.д.)
config/db_config.yaml	Твой личный файл с доступами к БД (не заливай на GitHub!)
